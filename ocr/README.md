Self-hosted, lazy-loaded Korean OCR assets from npm. Tesseract.js 6.0.1 (browser worker), tesseract.js-core 6.1.2 (portable LSTM WebAssembly build), and @tesseract.js-data/kor 1.0.0 (4.0.0_best_int model).
