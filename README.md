# 가계부 PWA (구글 스프레드시트 저장)

휴대폰 홈 화면에 설치해 쓰는 가계부예요. 모든 기록은 내 구글 스프레드시트에 저장돼요. 비용은 0원이에요.

## 1. 구글 시트 + Apps Script 준비 (5분)

1. [sheets.new](https://sheets.new)에서 새 스프레드시트를 만들어요. 이름은 아무거나 괜찮아요.
2. 메뉴에서 **확장 프로그램 → Apps Script**를 열어요.
3. 기본 코드를 지우고 `apps-script/Code.gs` 내용을 붙여넣어요.
4. 첫 줄 `TOKEN = '...'`을 **나만 아는 비밀번호**로 바꾸고 저장해요.
5. 오른쪽 위 **배포 → 새 배포 → 유형: 웹 앱**을 선택해요.
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
6. 권한 승인을 해요. "확인되지 않은 앱" 경고가 나오면 **고급 → 이동**을 누르면 돼요. 내가 만든 스크립트라서 괜찮아요.
7. 나온 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사해 둬요.

> Code.gs를 고친 뒤에는 **배포 관리 → 수정 → 버전: 새 버전**으로 다시 배포해야 반영돼요.

## 2. 앱 무료 배포 (GitHub Pages)

1. GitHub에 새 저장소를 만들고 이 폴더 파일을 올려요. `apps-script` 폴더는 빼도 돼요.
2. 저장소의 **Settings → Pages → Branch: main / (root) → Save**를 눌러요.
3. 1~2분 뒤 `https://내아이디.github.io/저장소이름/` 주소가 생겨요.

## 3. 휴대폰에 설치

- **아이폰**: 사파리로 주소를 열고 공유 버튼 → **홈 화면에 추가**를 눌러요.
- **안드로이드**: 크롬으로 주소를 열고 메뉴 → **앱 설치**(또는 홈 화면에 추가)를 눌러요.
- 앱을 처음 열면 **⚙ 설정**에 웹 앱 URL과 비밀번호를 넣어요.

## 동작 방식

- 입력하면 바로 화면에 보이고 곧이어 시트에 저장돼요.
- 인터넷이 끊겨 있으면 폰에 대기시켜 두었다가, 연결되거나 ⟳를 누르면 시트로 보내요.
- 시트에서 직접 행을 고치거나 지워도 앱에서 ⟳를 누르면 반영돼요. 단, `id` 열은 건드리지 마세요.
- 앱 파일을 고쳤다면 `sw.js`의 `CACHE` 버전을 올려야 폰에 새 버전이 받아져요.

## 보안 참고

웹 앱 URL과 비밀번호를 아는 사람은 기록을 읽고 쓸 수 있어요. 둘 다 남에게 공유하지 마세요.
