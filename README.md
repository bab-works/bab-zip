# 나의 가계부 PWA

휴대폰 홈 화면에 설치해 쓰는 가계부예요. 기존 구글 스프레드시트 **「나의 가계부」**를 그대로 저장소로 써요. 비용은 0원이에요.

## 기능

- **홈**: 월별 수입·지출(환불 차감, 이체 제외)·남은 돈을 보여줘요. 대분류별 예산 진행률도 나와요(80% 넘으면 주황, 100% 넘으면 빨강).
- **예산 알림**: 거래를 저장할 때 80%나 100%를 넘으면 알림을 띄워요. 🔔 버튼으로 휴대폰 알림을 켤 수 있어요. 예산 금액을 누르면 수정돼요(시트 `카테고리` 탭 E열).
- **내역**: 검색(내용·메모·카테고리·결제수단), 필터(구분·대분류·결제수단·전체 기간), 정렬(날짜·금액). 항목을 누르면 수정하거나 삭제할 수 있어요.
- **입력**: 지출·수입·환불·이체, 대분류→소분류, 결제수단, 할부 개월. 내용을 입력하면 `분류규칙` 탭의 키워드로 분류가 자동 선택돼요.
- **반복**: 매월 n일에 자동으로 기록돼요(통신비, 월세, 구독 등). 앱을 열 때 지난 달 분까지 채우고, 같은 달에 두 번 기록되지 않아요.
- **오프라인**: 인터넷이 끊겨도 입력할 수 있어요. 연결되면 시트로 보내요.

## 시트에 생기는 변화

- `거래` 탭 **O열에 `id`**가 생겨요. 기존 행에도 한 번 채워져요. 수정·삭제할 때 행을 찾는 용도라서 **지우거나 고치지 마세요.**
- **`반복` 탭**이 새로 생겨요.
- 앱은 `거래` 탭의 F열(결제유형)과 L~N열(할부 진행·남은 개월·총액)에는 쓰지 않아요. 이 열은 기존 수식이 계속 계산해요.
- 대시보드, 월별 탭, 할부 탭의 수식은 그대로예요.

## 1. Apps Script 배포 (1회)

1. 「나의 가계부」 시트를 열고 **확장 프로그램 → Apps Script**를 눌러요.
2. 기존 코드를 지우고 `Code.gs` 전체를 붙여넣은 뒤 저장해요. 비밀번호(`TOKEN`)가 들어간 파일은 따로 전달받아요.
3. **배포 → 새 배포 → 유형: 웹 앱**을 선택해요. 실행 사용자는 **나**, 액세스 권한은 **모든 사용자**로 두고 배포해요.
4. 권한 승인 창에서 **고급 → (안전하지 않음)으로 이동 → 허용**을 눌러요.
5. 웹 앱 URL(`…/exec`)을 복사해요.
6. (선택) 편집기 위쪽 함수 목록에서 `setupDaily`를 고르고 **실행**해요. 앱을 열지 않아도 매일 아침 6시에 반복 거래가 기록돼요.

> Code.gs를 고친 뒤에는 **배포 관리 → 수정(연필) → 버전: 새 버전 → 배포**를 해야 반영돼요. URL은 그대로예요.

## 2. 무료 배포 (GitHub Pages)

저장소의 Settings → Pages → Branch `main` / `(root)`로 설정하면 `https://아이디.github.io/저장소/` 주소가 생겨요.

## 3. 휴대폰에 설치

- 아이폰: 사파리에서 공유 → **홈 화면에 추가**를 눌러요. 알림은 iOS 16.4 이상, 홈 화면에서 실행할 때만 돼요.
- 안드로이드: 크롬 메뉴 → **앱 설치**를 눌러요.
- 처음 열면 ⚙ 설정에 웹 앱 URL과 비밀번호를 넣어요.

## 참고

- 앱 파일을 고쳤다면 `sw.js`의 `CACHE` 버전을 올려야 휴대폰에 새 버전이 받아져요.
- 웹 앱 URL과 비밀번호를 아는 사람은 가계부를 읽고 쓸 수 있어요. 둘 다 공유하지 마세요.
